# analysis · 解析与统计层（说明）

职责：把原始事件整理成可直接展示的结果，并对每个数字标注口径。

主要产物：

- 时间轴轨道：效果覆盖区间（区分原生事件通道 / 采样通道）；
- 伤害与治疗：逐次事件累计、分段统计、成员排行与占比；
- Boss 曲线：血量、真气的归一化序列，缺口显式标记；
- 减益覆盖：Boss 身上的减益区间与覆盖率，支持展开；
- 结算核对：游戏结算快照与逐次事件的对应关系，避免重复计入；
- RD 估算：在增益有效覆盖区间内累计队友真实技能伤害，乘有效系数。

原则：不猜、不重复、可核对、不越权（详见 `docs/data-scope.md`）。
